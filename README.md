A simple Project to sort/move all files from specific folders based on extensions. 

So basically we sort all files based on there extension and make folders named after the extension in upper case and we put all the files into there specific folder.


Note :

It is still ongoing and therefore not finished !

Furthermore, the current version is just a blueprint and can only sort within Downloads, Desktop and Documents folder . It also cannot sort nested folder that contain pdf files. And all files are safed/moved within there named extension.

Features to be added :

- a basic interface for the program 
- eventually adding a more dynamic solution for users to not be restricted to those 3 folders.
