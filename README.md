#Folder_sorter v0.01

A simple Project to sort all files from specific folders based on extensions. 

So basically we sort all files based on there extension and make folders named after the extension in upper case and we put all the files into there specific folder.


Note :

It is still ongoing and therefore not finished !

Furthermore, the current version is just a blueprint and can only sort within the Downloads folder and only pdf files . It also cannot sort nested folder that contain pdf files. And all pdf files are moved into a folder called PDF within the Documents folder.

Features to be added :

- user should be able to input which folder shall be sorted and where those files should be moved. 
- user should be able to only sort specific extension files for example only pdfs or py files etc. 
- a basic interface for the program
